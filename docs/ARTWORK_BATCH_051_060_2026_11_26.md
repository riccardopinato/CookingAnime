## Provenance / aesthetic QA
- 051: image created in ChatGPT ImageGen, original style-grounded illustration.
- 052–060: Adobe Firefly original image generations with detailed source-based food prompts. 057 and 058 selected only after multiple iterations to correct composition, color and number/order of dango.
- Relevant original refs from the existing image corpus (actual images, not keywords only): #001, #002, #006, #010, #025, #035 and #050.
- Visual style: warm Japanese interior, natural wood, food-first compositions, soft semi-realistic 2D anime food-film shading; **no anime frames, logos or franchise characters**.
- Semantic visual review was performed by the assistant on the produced artwork and canonical Italian recipes; this is **not a claimed user aesthetic signoff, human culinary certification, or automated VLM/style score**.
- Illustrations can show a representative serving instead of an exact total recipe yield; the recipe data remains definitive. #053 shrimp count and #058 single skewer are intentionally illustrative. They should be replaced if visual acceptance requires all portions.

## F3E invariants
Each asset is a JPEG `assets/recipe_artwork/recipe_0000NN.jpg`, the manifest review points at the exact source `contentVersion`, and production authoring `imageAssetId` points at one approved asset. The generated `assets/catalog/recipes.json` `imageAsset` path is synchronized without touching the six locale packs. Card uses `BoxFit.cover`; detail uses `BoxFit.contain`.
